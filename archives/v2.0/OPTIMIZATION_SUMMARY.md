## 🎯 核心改进详情

**新增文件**:
- `config/settings.yaml` - 主配置文件
- `infrastructure/config_manager.py` - 配置管理器

**特性**:
- ✅ YAML格式配置文件
- ✅ 支持环境变量覆盖
- ✅ 单例模式,全局统一配置
- ✅ 配置热重载能力
- ✅ 默认配置兜底

**配置项**:

### 2. 计算任务优化

**新增文件**:
- `infrastructure/calculation_handler.py` - 计算任务处理器

**改进**:
- ✅ 专门处理数学计算任务
- ✅ π值计算支持两种方式:
  - 预定义字符串(快速,适合≤100位)

- ✅ 移除main.py中的硬编码
- ✅ 配置驱动,灵活切换

## 🔧 配置使用指南

### 修改配置

编辑 `config/settings.yaml`:

```yaml
# 修改模型超时时间
models:
  local:
    default_timeout: 180  # 从120改为180

# 修改意图识别规则
intent:
  custom_rules:
    code:
      - "代码"
      - "写.*代码"
      - "你的自定义规则"
```

### 环境变量覆盖

```bash
# 设置Ollama地址
export OLLAMA_BASE_URL="http://192.168.1.100:11434"

# 设置超时时间
export CAMPFIRE_TIMEOUT=180
```

### 代码中使用配置

```python
from infrastructure.config_manager import config

# 获取配置值
timeout = config.get("models.local.default_timeout", 120)

# 获取模型配置
model_config = config.get_model_config("mindchat")

# 获取路由配置
routing = config.get_routing_config("code")
```
