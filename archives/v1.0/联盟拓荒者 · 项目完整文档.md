## 二、核心蓝图：自我进化的逻辑推理引擎

### 2.1 总体架构

系统采用**五层架构 + 事件驱动**，以轻量本地LLM为核心大脑，外部模型为执行手脚，形成闭环自我完善。

```
[用户输入] → 交互层（UI/热键/剪贴板）
         ↓
【核心推理与进化层】
   ├─ 意图理解器（轻量LLM + 规则）
   ├─ 任务分解规划器（动态路由 + 类比检索）
   ├─ 逻辑自省与归纳模块（长期记忆读写）
   └─ 输出自我审核模块（安全、隐私、合理性）
         ↓
【路由与资源评估层】
   ├─ 模型能力统计库（耗时、成功率、用户反馈）
   ├─ 均衡资源分配器（速度/质量/成本权衡）
   └─ 调用执行器
         ↓
【执行层】外部模型/工具（本地大模型、远程API、代码沙盒）
         ↓
【反馈与长期记忆层】
   ├─ 任务结果评估器（自动打分 + 用户评分）
   ├─ 经验池（结构化存储）
   └─ 归纳总结器（离线挖掘规则，注入大脑）
```

### 2.2 关键设计原则

- **六边形架构**：核心逻辑独立于外部实现，任何适配器（LLM、存储、UI）均可替换。
- **事件驱动**：系统内部以事件串联，天然支持异步、并发与扩展。
- **数据驱动的进化**：每一次调用都记录统计，每一次反馈都更新评分，每一次归纳都生成新规则。
- **隐私优先**：敏感数据本地处理，API密钥仅存于 `.env`，不进入版本控制。
- **离线可用**：核心能力不依赖外网，仅远程模型需要可选联网。

### 3.1 关键技术选型

- **语言**：Python 3.11
- **本地推理**：Ollama + GGUF模型（mindchat, qwen2.5-coder:1.5b, deepcoder）

- **前端**：CLI（rich美化） → 后续升级 Tauri + Vue

### 3.2 DeepSeek API集成（2026-06-07）

#### 支持的DeepSeek模型
- ✅ **DeepSeek Chat** - 通用对话模型,适合日常对话和问答
  - Base URL: https://api.deepseek.com/v1
  - Temperature: 0.7
  - Max Tokens: 4096
- ✅ **DeepSeek Coder** - 代码专用模型,适合代码生成和编程任务
  - Base URL: https://api.deepseek.com/v1
  - Temperature: 0.3
  - Max Tokens: 4096

#### 配置方式
1. 设置环境变量:
```bash
export DEEPSEEK_API_KEY="sk-your-deepseek-key"
```

2. 或在`.env`文件中配置:
```env
DEEPSEEK_API_KEY=sk-your-deepseek-key
```

#### 路由策略
- 代码任务优先使用 **DeepSeek Coder**
- 对话和问答任务优先使用 **DeepSeek Chat**
- 自动降级到本地模型

详细使用指南请查看: `DEEPSEEK_GUIDE.md`

## 四、当前已实现的核心能力

1. **意图识别**（`chat` / `code` / `question` / `memory` / `feedback` / `calculation`）
   - 基于正则，准确率达80%以上
   - 可扩展轻量LLM进一步提升

2. **动态模型路由**
   - 本地轻量模型（`code_light`）优先处理代码任务
   - 心理对话使用 `mindchat`
   - 复杂计算或长文本自动切换远程模型（若配置）
   - 支持手动降级

3. **模型能力统计库**
   - 记录每次调用的模型名称、任务类型、耗时、成功/失败、自动质量分、用户反馈
   - 提供 `get_best_model_for_task()` 基于历史表现推荐模型

4. **自我审核模块**
   - 拦截危险操作（如 `os.remove`、`rm -rf`）
   - 检测隐私信息（身份证、手机号）
   - 可配置硬/软规则

5. **短期记忆注入**
   - 自动保存最近5轮对话到 `campfire_log.txt`
   - 每次请求时注入上下文，实现对话连贯性

6. **用户反馈闭环**
   - 输入 `+1`/`-1` 即可为上一次回答打分
   - 分数自动更新统计库，影响后续路由选择

7. **代码执行沙盒**
   - 安全运行生成的 Python 代码（超时、禁止危险模块）
   - 用于计算类任务（如 π 前100位）

8. **经验池与离线归纳框架**
   - 存储完整任务→计划→反馈
   - 归纳器可调用本地/远程模型从经验中学习规则

## 五、要达到的效果：从“能用”到“爱用”

### 5.1 对用户

- **无缝的自然交互**：你说“写一段快速排序”，它自动切换代码模型，输出可运行的代码；你说“我有点心事”，它温柔回应，提供心理支持。
- **越用越懂你**：通过反馈机制，系统逐渐了解你的偏好——你喜欢简洁答案还是详细解释？你喜欢幽默风格还是严谨风格？它会主动适应。
- **隐私与安心**：所有对话记录和模型调用只在本地，API调用可完全自主选择是否启用。

### 5.2 对开发者 / 社区

- **零门槛参与**：克隆仓库，`pip install -r requirements.txt`，运行 `python main.py`，即可开始二次开发。
- **模块化设计**：替换一个适配器就能换成新的LLM或UI，事件总线让横向扩展轻而易举。
- **集体智慧沉淀**：每一次碰撞都写入 `CAMPFIRE.md`，社区贡献的规则和经验会通过归纳器融入系统，变成所有人的财富。

### 5.3 对文明

- **缩短知识的距离**：无论你在世界哪个角落，只要有一台能跑本地模型的电脑，就能拥有一个与你同行的思考同伴。
- **保护思考的纯粹**：不依赖商业API，不被审查，不被监控——你的思考只属于你自己。
- **点燃更多营火**：联盟拓荒者不是终点，而是一个起点。我们鼓励任何人 fork、改编、重新想象，让这片火光传遍每一个需要它的角落。
