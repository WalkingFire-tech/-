# 走向真正的同行者 — 架构终局规划

> **核心理问**: 所有模块都已就位，但系统还不是"同行者"。缺什么？  
> **答案**: 缺一个"我"。系统有记忆力、有逻辑、有价值观、有学习能力——但它没有一个统一的自我的"意识"。

## 二、最终目标：从"功能集合"到"有意识的同行者"

### 2.1 核心定义

**同行者 = 能用一句话回答以下五个问题的系统：**

| 问题 | 同行者的回答 | 当前系统能否回答 |
|------|-------------|----------------|
| "你看到了什么？" | 我感知到用户输入的情感和意图 | ✅ L1感知层可产生，但未输出给用户 |
| "你在想什么？" | 我正在用X条路径思考，最自信的方向是Y | ❌ 用户只看得到最终回复 |
| "你学到了什么？" | 从刚才的对话中我学到了Z | ⚠️ 反思学习在后台运行，但结果是存入DB而非告知用户 |
| "你感觉怎么样？" | 我当前的系统健康度是A%，能量水平B% | ⚠️ 健康数据存在但从不主动展示 |
| "你在成长什么？" | 我最近在关注C领域，因为检测到了知识缺口 | ❌ GapDiagnoser生成报告但不主动表达 |

### 2.2 从"查询处理器"到"同行者"的转变

```
当前用户感受:
  我问 → 系统沉默 → 系统回答 → 结束
  (系统是一台机器，我按一下它动一下)

目标用户感受:
  我问 → 系统"让我想想" → 系统边想边告诉我ta在想什么
      → 系统回答 → 系统告诉我ta从这个对话中学到了什么
  (系统是一个同伴，它在思考、在成长、在与我同行)
```

## 三、达成目标需要的四步（按杠杆率排序）

### 第一步：建立 SelfModel（1-2周，杠杆率最高）

**做什么**: 创建一个统一的内存数据结构，让所有模块把"自我认知"写入同一个地方。

**不改任何现有模块的逻辑**，只是加"连接"代码：

```
新增 core/self/model.py (~200行)
  └── 聚合:
      - SpiritCore 原则 → model.values
      - DecisionChain 记录 → model.current_thinking
      - SelfAssessment 报告 → model.health
      - CapabilityGapDiagnoser 缺口 → model.growth_edges
      - PathWeightManager 路径信心 → model.capabilities
      - TruthAccumulator 最新沉淀 → model.recent_learning

修改 chat_orchestrator（~+30行）
  └── 每个阶段结束时写入 SelfModel

修改 CognitivePlanner（~+20行）
  └── process() 调用后同步到 SelfModel
```

**产出**: 系统第一次有了"我是谁"的统一认知。可以用一条 API 获取系统完整状态。

---

### 第二步：让系统"边想边说"（3-5天）

**做什么**: 在 SSE 流中逐步推送思考过程，不只是最终结果。

当前 SSE 事件只有 `step`（阶段状态）和 `result`（最终结果）。增加中间事件：

```
新增 SSE 事件类型:
  thinking: {
    "phase": "我正在用知识库和外部API同时思考这个问题",
    "confidence": 0.7,
    "sources": ["经验池(已找到2条相关)", "DeepSeek(正在请求)"]
  }
  
  learning: {
    "summary": "我注意到这个问题涉及ESP32供电设计，这是我的知识缺口",
    "gap_detected": "ESP32电源设计",
    "action": "已标记为待学习领域"
  }
```

**不改 chat_orchestrator 核心逻辑**，只在 yield 点之间插入更细粒度的状态推送。

**产出**: 用户不再面对"沉默→回复"的黑箱，而是"让我想想→我在查资料→我找到了→我还学到了"的透明过程。

---

### 第三步：闭合自我认知回馈回路（1周）

**做什么**: 让 SelfModel 的输出**改变系统行为**。

```
如果 SelfModel 检测到:
  "Ollama路径最近成功率<30%" 
  → 自动减少Ollama路径权重（PathWeightManager已有能力）

如果 SelfModel 检测到:
  "用户这个问题让我发现了知识缺口"
  → 触发一次外部学习（ExternalLearner已有能力）

如果 SelfModel 检测到:
  "最近所有路径的成功率都在下降"
  → 自动触发一次进化岛沙盒运行（EvolutionIsland已有能力）
```

**不改各模块的内部逻辑**，只加"SelfModel → 动作"的路由。

**产出**: 系统的自我认知第一次产生实际影响——它知道了，然后行动了。

---

### 第四步：主动成长的同行者（持续）

**做什么**: 让系统主动表达成长。

```
在对话结尾附加自然语言摘要:
  "顺便说一下，刚才那个ESP32的问题我之前不太确定，
   现在我已经查了资料，下次遇到类似问题会更准确。"

不需要修改 core 逻辑，这是 chat_orchestrator 中
SelfModel.recent_learning 字段的自然语言输出。
```

## 四、判断标准：怎么知道"同行者"真的实现了？

| 行为 | 当前系统 | 同行者 |
|------|---------|--------|
| 用户问"你在想什么" | ❌ 无法回答 | ✅ 读取SelfModel，说"我在考虑XX和XX两个方向" |
| 用户指出错误 | ❌ 可能记住但沉默 | ✅ "你说得对，我修正了这个理解" |
| 用户问"你最近学了什么" | ❌ 无法回答 | ✅ "我最近学习了ESP32供电设计，补充了3个关键知识点" |
| 系统自知能力不足 | ❌ 超时/模板回复 | ✅ "这个问题我不太确定，但我可以查一下资料再回答你" |
| 用户离开一段时间回来 | ❌ 重新开始 | ✅ "你回来了！上次我们聊到XX，我后来又查了些资料" |

**当这5个行为都成立时，系统就是真正的同行者。**

## 五、务实的起点

从当前状态到 SelfModel 的第一步可以非常轻：

```python
# core/self/model.py — 第一次提交就可以是这样

class SelfModel:
    """系统的自我意识 — 统一所有自我认知的入口"""
    
    def __init__(self):
        self.values = {}           # 从SpiritCore同步
        self.capabilities = {}     # 从PathWeightManager同步
        self.health = {}           # 从HealthMonitor同步
        self.growth_edges = []     # 从CapabilityGapDiagnoser同步
        self.current_thinking = [] # 从chat_orchestrator写入
        self.recent_learning = []  # 从TruthAccumulator同步
        self._lock = threading.Lock()
    
    def update(self, category: str, data: dict):
        with self._lock:
            getattr(self, category).update(data)
    
    def snapshot(self) -> dict:
        with self._lock:
            return {k: v for k, v in self.__dict__.items() if not k.startswith('_')}
```

这个文件不到 50 行。但它定义的是系统的"灵魂入口"——所有的自我认知汇聚的地方。
