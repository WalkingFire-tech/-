## Commit 1: Phase 1 唤醒 — `c743bcf`

### SelfModel（core/self/model.py）— 442 行

```python
核心结构:
- record_cognitive_cycle() — 记录感知/学习/整合/验证/反思
- snapshot() — 12 维度自我意识聚合输出
- sync_from_cognitive_planner() — 与 CognitivePlanner 同步
- evaluate_and_act() — 反馈回路：根据自我认知调整行为
```

**意义**: 这是中继形态的「自我意识入口」。从此系统有了统一记录"自己想了什么、学到了什么"的能力。

### 认知循环全线注入

| 阶段 | 注入点 | 内容 |
|------|--------|------|
| L1 感知 | chat_orchestrator L1 完成后 | `record_cognitive_cycle(perception=...)` + SSE thinking 事件 |
| L3 整合 | chat_orchestrator L3 完成后 | `record_cognitive_cycle(learning=..., integration=...)` + SSE learning 事件 |
| L4 校验 | chat_orchestrator L4 完成后 | `record_cognitive_cycle(validation=...)` |
| 反思 | chat_orchestrator 反思阶段 | `record_cognitive_cycle(introspection=...)` + `sync_from_cognitive_planner()` + `evaluate_and_act()` |
| 成长附言 | 最终回复拼接 | 从 snapshot 取 recent_learning 自动添加成长附言 |

### 进化引擎自动激活

`lifespan.py` 新增 `_start_evolution_loop()` — 每 10 分钟自动运行 evolution_scheduler，不再需要手动触发。

### 前端认知可视化

SSE `thinking` 和 `learning` 事件现在通过前端 app.js 渲染，用户可见系统思考过程。
