# 自主求知策略

> 来源：知识来源的一些感想.txt，2026年6月
> 核心洞察：系统应学会通过多种途径问自己或问模型，获取高质量的网络数据源

## 搜索源分类与优先级

### 学术论文源（置信度0.90+）
- arXiv — 物理CS数学等领域最新研究
- Zenodo — 多学科开放科学仓库
- Semantic Scholar — AI驱动的学术搜索
- ScienceDirect/Nature/Sage — 顶级期刊

### 中文技术社区（置信度0.75-0.85）
- 极客公园 — AI/科技趋势深度分析
- 智源社区 — 国内AI研究前沿
- 阿里云开发者社区 — 工程实践与架构
- 百度开发者中心 — 技术选型与最佳实践
- 知乎专栏 — 深度观点与经验分享
- CSDN — 开发者教程与工具链

### 开源生态（置信度0.70-0.80）
- NPM/PyPI — 开源包与框架
- GitHub — 源码与README

### 图书与评论（置信度0.65-0.75）
- 豆瓣/微信读书 — 书评与摘要
- 多抓鱼 — 二手书信息

## 自主求知三步法

### 第一步：问网络（多源搜索）
1. 识别查询类型（学术/技术/社区/通用）
2. 选择对应站点组进行站点限定搜索
3. 对高质量源进行深度抓取

### 第二步：问自己/问模型（LLM推理）
1. 使用本地Ollama或外部API进行深度推理
2. 分析搜索结果的共识与分歧
3. 生成自己的见解和建议

### 第三步：综合沉淀
1. 提炼核心观点（2-3条）
2. 标注需要进一步验证的观点
3. 将综合分析存入知识库

## 关键原则

- **多源交叉验证**：不依赖单一来源，至少2个独立来源确认
- **置信度分层**：学术论文>技术社区>博客评论
- **自主综合**：不只是搬运搜索结果，要添加自己的分析和见解
- **优雅降级**：外部API不可用时降级到本地Ollama
