# 真谛沉淀与认知重组安全机制

> 来源：core/truth_accumulator.py，2026年6月设计实现

## 核心思想

从交互中提炼"真谛"——那些跨域普适、逻辑自洽、能降熵、反脆弱的洞察。不是所有知识都是真谛，真谛需要通过四道筛子。

## 四道筛子（真谛升级评估）

1. **跨域普适**（cross_domain）——这条真谛是否在多个领域都成立？
2. **逻辑自洽**（logical_consistency）——这条真谛内部是否有矛盾？
3. **认知降熵**（entropy_reduction）——这条真谛能否减少认知混乱？
4. **反脆弱性**（antifragility）——这条真谛是否越被挑战越强？

只有通过全部四道筛子的真谛才能从L3升级到L4。

## 认知重组安全协议

```
提案生成 → 人类批准 → 沙盒验证 → 1%注入 → 20%注入 → 100%注入
```

- 提案：系统自动生成重组候选，但不自动执行
- 人类批准：必须人类明确批准才能继续
- 沙盒验证：在隔离环境中测试重组效果
- 渐进注入：1%→20%→100%，每步观察认知熵值变化
- 回滚机制：任何阶段熵值>0.7，立即回滚

## 认知熵值监测

```
entropy = contradiction_rate × 0.5 + truth_conflict_rate × 0.15 + gene_safety_violations / 10 × 0.2
```

- <0.3: normal
- 0.3-0.5: warning
- \>0.5: critical（建议回滚）

**重要教训**：矛盾率不能把"多策略部分失败"算进去。5条路径中3条成功2条失败是正常的，只有"全部失败"才是真正的矛盾。
