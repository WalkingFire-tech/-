# 技能涌现机制

> 来源：core/skill_emergence.py，2026年6月设计实现

## 核心思想

技能不是预先定义的，而是从反复成功的模式中自然涌现的。就像人类在实践中形成习惯和直觉。

## 涌现条件

- 同一类问题成功解决3次以上 → 技能萌芽
- 成功率>60% → 技能成熟
- 成功率<30% → 技能退化

## 技能结构

```json
{
  "skill_name": "方法导航员_如何",
  "skill_type": "methodology",
  "trigger_patterns": ["如何", "怎么", "怎样"],
  "solution_path": "先确定解决方式→选择验证范式→多方案并行",
  "success_count": 5,
  "fail_count": 0,
  "success_rate": 1.0
}
```

## 技能驱动的方法论发现

当技能库中有匹配技能时，方法论发现会优先使用技能驱动的策略，而非从零开始分析。这实现了"有好的方法或创造方法的方法"这一元能力。

## 当前涌现的技能

| 技能 | 触发模式 | 成功率 |
|------|----------|--------|
| 方法导航员_如何 | 如何/怎么/怎样 | 100% |
| 代码验证师 | 代码/编程/函数/STM32 | ~80% |
| 本质推理师 | 为什么/是什么/原理 | ~70% |
