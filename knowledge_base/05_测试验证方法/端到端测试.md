# 端到端测试与验证方法

> 来源：tests/e2e_test.py，2026年6月设计实现

## 测试场景

| 编号 | 场景 | 验证点 | 结果 |
|------|------|--------|------|
| 1 | 简单问候 | 意图=greeting，快速路径<3秒 | ✅ 2.0s |
| 2 | 科学事实 | 本质推理+领域感知免责+多源交叉验证 | ✅ 76.5s |
| 3 | 代码工程 | 代码验证6/6+不触发科学免责 | ✅ 34.3s |
| 4 | 悖论 | 本质闸门识别+不触发科学免责+不判推理链断裂 | ✅ 34.3s |
| 5 | 质疑 | 意图=challenge(90%) | ✅ 2.1s |
| 6 | 上下文 | 对话历史传递+前文引用 | ✅ 64.0s |

## 验证范式总结

### 科学事实问题
- 本质推理6步全部执行
- 领域感知免责（物理→物理学会，生物→Nature/Science）
- 多源交叉验证（Ollama + DeepSeek + 知识库）
- 免责声明用`---`分隔，标注"非立论依据"

### 代码/工程问题
- 跳过科学事实提取（代码块占比>40%）
- 跳过科学免责
- 执行代码验证：括号匹配、函数声明、return检查、算法逻辑检查
- 二分查找模拟运行6个测试用例

### 悖论/哲学问题
- 本质闸门识别为"定义边界问题"
- 跳过推理链断裂检查
- 跳过科学免责
- 提前返回，不强行追溯基本原理

### 质疑/challenge
- 意图识别为challenge
- 获取上一轮回复
- 重新验证并给出修正

## 测试命令

```bash
python tests/e2e_test.py 1    # 测试1: 问候

python tests/e2e_test.py 4    # 测试4: 悖论
python tests/e2e_test.py 5    # 测试5: 质疑
python tests/e2e_test.py 6    # 测试6: 上下文
python tests/e2e_test.py      # 全部测试
```
