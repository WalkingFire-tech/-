# 基因池与认知代谢

> 来源：core/task_queue.py，2026年6月设计实现

## 基因池

系统有一组可进化的"基因"参数，控制系统的行为倾向：

| 基因 | 含义 | 安全区间 |
|------|------|----------|
| timeout_tolerance | 超时容忍度 | [0.5, 3.0] |
| depth_preference | 深度偏好 | [0.1, 0.9] |
| self_doubt_frequency | 自我怀疑频率 | [0.3, 0.9] |
| exploration_rate | 探索率 | [0.1, 0.8] |
| learning_rate | 学习率 | [0.01, 0.5] |

### 基因安全基线

每个基因都有不可逾越的安全区间。`mutate()`操作会强制clamp到安全区间内：

```python
GENE_SAFETY_BOUNDS = {
    "timeout_tolerance": (0.5, 3.0),
    "depth_preference": (0.1, 0.9),
    ...
}
```

## 认知代谢

经验池定期压缩排毒，每10次交互触发：

1. **高质量经验保留** — quality_score高的经验永久保留
2. **超时经验清理** — 超时未完成的经验降级或删除
3. **碎片整理** — 空闲>5分钟时自动触发

## 进化压力测试

随机环境扰动注入器，每50次交互触发：

- Ollama不可用时的降级测试
- 外部API超时时的回退测试
- 基因突变越界时的安全基线测试
- 数据库损坏时的恢复测试

## 持久化任务队列

支持延迟执行和优先级的任务队列：

```python
task_queue.enqueue("deep_thinking", data, priority=3, delay_seconds=15)
task_queue.enqueue("model_review", data, priority=7, delay_seconds=5)
```

- 任务持久化到SQLite，重启后自动恢复
- Worker线程后台执行，不阻塞主流程
