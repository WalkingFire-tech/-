# 基因池与认知代谢

> 来源：core/task_queue.py，2026年6月设计实现，v3.2.0更新

## 基因池

系统有10个可进化的"基因"参数，控制系统的行为倾向：

| 基因 | 含义 | 安全区间 | 默认值 |
|------|------|----------|--------|
| curiosity_weight | 好奇心权重 | [0.1, 1.0] | 0.75 |
| caution_threshold | 谨慎阈值 | [0.3, 1.0] | 0.78 |
| learning_rate | 学习率 | [0.01, 0.5] | 0.3 |
| timeout_tolerance | 超时容忍度 | [0.3, 2.0] | 2.0 |
| depth_preference | 深度偏好 | [0.2, 0.9] | 0.2 |
| confidence_bias | 置信度偏置 | [0.1, 0.9] | 0.5 |
| retry_aggression | 重试激进程度 | [0.1, 1.0] | 0.5 |
| knowledge_solidify_threshold | 知识固化阈值 | [0.5, 0.95] | 0.8 |
| model_preference_speed | 模型速度偏好 | [0.0, 1.0] | 0.7 |
| self_doubt_frequency | 自我怀疑频率 | [0.1, 0.8] | 0.3 |

### 基因安全基线

每个基因都有不可逾越的安全区间。`mutate()`操作会强制clamp到安全区间内：

```python
GENE_SAFETY_BOUNDS = {
    "curiosity_weight": (0.1, 1.0),
    "caution_threshold": (0.3, 1.0),
    "learning_rate": (0.01, 0.5),
    "timeout_tolerance": (0.3, 2.0),
    "depth_preference": (0.2, 0.9),
    ...
}
```

### 基因表达谱

基因池提供5维雷达图表达谱（aggressive/cautious/patient/confident/fast），用于前端可视化展示系统"性格"。

## 认知代谢

经验池定期压缩排毒，通过持久化任务队列触发（经验池总数为10的倍数时入队）：

1. **高质量经验保留** — quality_score>=70的经验质量分+5（上限95）
2. **低价值经验清理** — quality_score<50且>30天的经验删除
3. **知识库排毒** — quality<30且>30天的知识删除

## 进化压力测试

随机环境扰动注入器，经验池总数为50的倍数时入队：

- Ollama不可用时的降级测试
- 外部API超时时的回退测试
- 基因突变越界时的安全基线测试
- 数据库损坏时的恢复测试

## 持久化任务队列

支持延迟执行和优先级的任务队列：

```python
task_queue.enqueue("deep_thinking", data, priority=3, delay_seconds=15)
task_queue.enqueue("model_review", data, priority=7, delay_seconds=5)
```

- 任务持久化到SQLite，重启后自动恢复
- Worker线程后台执行，不阻塞主流程
