# 认知调度器与意图路由

> 来源：core/cognitive_dispatcher.py，2026年6月设计实现

## 核心思路

不同类型的问题需要不同的处理策略。认知调度器是系统的"前台"，负责识别问题类型并路由到正确的处理管道。

## 意图类型

| 意图 | 触发词 | 路由 | 复杂度 |
|------|--------|------|--------|
| greeting | 你好/hi/hello | fast | 0.1 |
| confirmation | 好的/是的/确认 | fast | 0.1 |
| challenge | 你确定/真的吗/不对吧 | slow | 0.8 |
| history | 之前/上次/刚才 | slow | 0.5 |
| complex_query | 其他所有 | slow | 0.5-1.0 |

## 路由决策

```
fast路径: 直接回复，2秒内完成
slow路径: 完整9阶段处理，30-80秒
```

## 关键设计

### 超短句特殊处理
- ≤8字符的输入只检查greeting/confirmation/challenge
- 避免短句被误判为complex_query

### challenge匹配策略
- 使用包含匹配而非精确匹配
- "你确定吗"包含"确定吗"→匹配成功
- 置信度基于关键词长度占比

### 缓存机制
- 相同问题300秒内直接返回缓存结果
- 避免重复计算
