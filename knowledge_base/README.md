## 使用方式

- 每个文件独立可读，不依赖其他文件
- 文件名即内容摘要
- 新增知识直接在对应目录下新建文件
- 跨领域知识放在06_对话精华与灵感
- 外部参考资料放在07_论文与参考资料

## 贡献指南

1. 一个文件一个主题
2. 文件开头标注来源和日期
3. 包含"核心思路"、"关键设计决策"、"教训"三个部分
4. 用表格和代码块增强可读性
