# OLD存档区 — R5铁律执行目录

> **R5铁律**: 禁止删除任何已编码但未接入的模块或悬空文件——能力存在即资产，未经严格论证无用者只能移至OLD存档，永不删除。

## 目录结构

```
_arch/OLD/
├── suspended_modules/   — 已编码但未接入主流程的模块（待接入或待论证无用）
├── dead_code/           — 经严格论证确认为无用的代码（从源码移至此处，保留可追溯性）
└── deprecated/          — 已被新模块替代的旧版本代码
```

## 使用规则

1. **移入条件**：经严格论证（至少2人确认或自动化测试证明0引用+0测试覆盖+0计划使用）确认为无用
2. **移入操作**：`git mv <源文件> _arch/OLD/<子目录>/`，保留完整git历史
3. **移入后**：在INVENTORY.md中记录移入原因、日期、原路径
4. **恢复操作**：`git mv _arch/OLD/<子目录>/<文件> <原路径>`，更新INVENTORY.md
5. **绝对禁止**：直接`git rm`删除任何已编码模块文件

## 与_arch/suspended_modules/的区别

- `_arch/suspended_modules/` — 存放**悬空模块的清单和元数据**（INVENTORY.md），模块源码仍在core/等原始位置
- `_arch/OLD/suspended_modules/` — 存放**已从源码位置移出的模块文件本身**
