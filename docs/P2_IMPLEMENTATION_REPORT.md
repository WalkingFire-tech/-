### 2.2 结果融合器 (result_fusion.py)

**功能定位**: 将多个子任务结果整合为连贯答案

#### 四种融合策略

| 策略 | 适用场景 | 实现方式 |
|------|----------|----------|
| **concat** | 简单拼接 | 添加段落标题，顺序组合 |
| **summarize** | 代码+解释 | LLM总结，生成连贯回答 |
| **best** | 纯代码任务 | 选择质量最高的结果 |
| **merge** | 有依赖关系 | 考虑上下文的智能合并 |

#### 自动策略选择

```python
def _select_strategy(self, subtasks, results) -> str:
    types = [t['type'] for t in subtasks]
    
    # 纯代码 → best
    if all(t == 'code' for t in types):
        return 'best'
    
    # 代码+解释 → summarize
    if any(t in ['explanation', 'analysis'] for t in types):
        return 'summarize'
    
    # 有依赖 → merge
    if any(t.get('dependencies') for t in subtasks):
        return 'merge'
    
    # 默认 → concat
    return 'concat'
```

#### 融合示例

```
子任务结果:
1. [代码] def quicksort(arr): ...
2. [解释] 快速排序的平均时间复杂度为O(n log n)...

融合结果 (concat策略):
### 代码实现
def quicksort(arr):
    ...

### 解释说明
快速排序的平均时间复杂度为O(n log n)...
```

## 三、Planner集成

### 3.1 完整执行流程

```
用户输入
  ↓
意图识别 + 复杂度检测
  ↓
┌─ 简单任务 → 单模型路由
│
├─ 复杂任务 → 智能分解
│   ↓
│   任务分解（LLM/规则）
│   ↓
│   子任务并行执行
│   ├─ 子任务1 → 联邦调度 → 结果1
│   ├─ 子任务2 → 联邦调度 → 结果2
│   └─ 子任务3 → 联邦调度 → 结果3
│   ↓
│   结果融合（自动策略）
│   ↓
│   完整答案
│
└─ 失败降级 → 联邦调度 → 单模型
```

### 3.2 关键集成代码

```python
def _decompose_and_execute(self, intent: Intent) -> Optional[str]:
    """分解复杂任务并执行"""
    # 1. 分解任务
    subtasks = self.task_decomposer.decompose_with_llm(intent.raw_text)
    
    # 2. 执行子任务
    results = []
    for subtask in subtasks:
        result = self._parallel_schedule(subtask)
        results.append(result)
    
    # 3. 融合结果
    fused_result = self.result_fusion.fuse(
        subtasks=subtasks,
        results=results,
        original_intent=intent.raw_text,
        strategy='auto'
    )
    
    return fused_result
```
