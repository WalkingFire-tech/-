# ============================================
# 关键点总结
# ============================================

1. 纠错必须包含关键词："不对"、"应该是"、"错误"、"正确答案是"
2. 纠错后系统会自动记住知识
3. 下次问同样问题就能正确回答
4. 知识会累积，越用越聪明
5. 种子知识只是初始值，用户可以不断添加
