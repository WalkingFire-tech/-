```
    ↓                 │

    ↓                 │
L4 校验层            │
    ↓                 │
    ├──通过→ L5进化层 ──┘
    │                 │
    └──不通过→ 回退到L2

    ↓                 │
L6 内省层（更新健康度）
    ↓                 │
响应输出
    ↓                 │
（进入对话间隙）←──────┘

第零层持续运作
```
