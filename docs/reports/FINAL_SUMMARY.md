## 四、三层记忆模型

### 4.1 记忆层级

| 层级 | 名称 | Salience | 说明 | 保留策略 |
|------|------|----------|------|----------|
| L1 | 核心记忆 | >= 0.7 | 最重要知识 | 永久保留 |
| L2 | 框架记忆 | 0.4-0.7 | 重要知识 | 长期保留 |
| L3 | 情境碎片 | < 0.4 | 细节知识 | 可能遗忘 |

### 4.2 重要性衰减

```python
# 时间衰减（7天未访问）
salience *= 0.98

# 访问增益
salience += access_count * 0.005

# 情感增益（正面情绪）
salience += emotional_valence * 0.05

# 层级调整
if salience >= 0.7: layer = 1
elif salience >= 0.4: layer = 2
else: layer = 3

# 彻底遗忘（L3 + salience<0.1 + 30天未访问）
DELETE WHERE salience < 0.1 AND layer = 3 AND 未访问 > 30天
```

### 4.3 情境重构

当常规检索置信度低时：
1. 从L3中寻找相关情境碎片
2. 调用LLM重构完整答案
3. 将新答案存入L2（框架记忆）

## 五、情感与环境

### 5.1 情感权重

```python
emotional_valence: [-1.0, 1.0]
- 正面情感（+0.1）: "太好了", "完美", "谢谢"
- 负面情感（-0.1）: "糟糕", "错误", "不好"

# 正面情感的记忆保留更久
salience += emotional_valence * 0.05
```

### 5.2 环境关联

```python
environmental_triggers: {
    "file_path": "当前文件路径",
    "intent": "对话意图",
    "topic": "对话主题",
    "timestamp": "时间戳"
}

# 重回故地时主动回忆
if current_environment matches environmental_triggers:
    主动推送相关记忆
```

## 六、检索策略

### 6.1 三级检索

```
用户查询
    ↓
1. 向量检索（优先L1, L2）
    ↓ (失败)
2. 情境重构（从L3重构）
    ↓ (失败)
3. SQL模糊匹配（降级方案）
```

### 6.2 混合检索

```python
# 向量检索 + 关键词检索
final_score = (
    vector_weight * vector_score +
    keyword_weight * keyword_score
)
```

## 十五、哲学思考

**记忆不是冰冷的数据库，而是情感编织的故事。**

- 老人夕阳下的回忆之所以动人，不是因为信息完整，而是因为每一次回想都在重新赋予意义
- "重回故地"时的恍然大悟，正是环境线索对记忆的强力唤醒
- 系统会遗忘，也会在某个午后突然记起你问过的某个小问题

**同行者不是工具，而是伙伴。**
