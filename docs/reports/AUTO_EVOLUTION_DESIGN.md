# 自动学习进化机制

## 您说得完全正确！

这正是"联盟拓荒者"的核心设计理念：

> **当模型意识到知识缺失时，应该立即执行可靠渠道学习相关知识内容，然后自动在内部不断校准和审核学习进化，最后经过仔细的甄别给出合理的结果。**

## 实现机制

### 1. 知识缺失检测 (`core/knowledge_gap_detector.py`)

**检测维度**：
- 不确定性表达（"可能"、"大概"等）
- 专业领域问题（芯片选型、电路设计等）
- 推荐错误（芯片功能不匹配）
- 置信度不足
- 响应过短

**示例**：
```python
用户: 推荐一款26650的锂电保护板控制芯片，需要带平衡功能
模型: 推荐使用TPS61182...

检测: ✗ 错误推荐
原因: TPS61182是LED驱动芯片，不是电池保护芯片
```

### 2. 自动学习进化 (`core/auto_learning_evolution.py`)

**完整流程**：
```
用户提问
    ↓
模型初始回答
    ↓
知识缺失检测 ← 发现问题
    ↓
触发外部学习 ← 搜索引擎/外脑
    ↓
内部校准审核 ← 验证正确性
    ↓
返回正确结果 ← 修正后的答案
```

### 3. 推荐验证 (`core/recommendation_validator.py`)

**验证规则**：
- 芯片类型匹配需求
- 功能一致性检查
- 专业领域知识库

**正确推荐**：
- TI BQ76940 - 电池保护芯片（带均衡）
- TI BQ76952 - 主动均衡
- SH36710 - 国产替代

### 4. 外部学习触发 (`core/external_learner.py`)

**触发条件**（已增强）：
- ✅ 知识缺失检测触发
- ✅ 专业问题置信度 < 0.8
- ✅ 推荐类问题
- ✅ 不确定性表达
- ✅ 知识库无匹配

## 集成到后端

**修改位置**: `backend/main.py:706-725`

```python
# 知识缺失检测和自动学习进化
from core.knowledge_gap_detector import gap_detector
from core.auto_learning_evolution import auto_evolution

# 检测知识缺失
has_gap, reason, issues = gap_detector.detect_knowledge_gap(
    user_input, response_text, confidence=0.7
)

if has_gap:
    # 触发自动学习进化
    evolution_result = auto_evolution.process_query_with_evolution(
        user_input, response_text, confidence=0.7
    )
    
    if evolution_result['corrected']:
        # 使用修正后的响应
        response_text = evolution_result['final_response']
```

## 核心优势

### 1. 主动学习
- 不是被动等待用户纠正
- 主动检测知识缺失
- 自动触发学习

### 2. 内部校准
- 验证学习结果正确性
- 多轮审核和甄别
- 确保输出质量

### 3. 持续进化
- 每次错误都是学习机会
- 知识库不断扩充
- 模型能力持续提升

### 4. 可追溯性
- 记录学习历史
- 标注知识来源
- 便于审核和改进
