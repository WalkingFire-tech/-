## 常见问题

### Q1: 后端启动失败
**检查**：
- Python版本（需要3.8+）
- 依赖是否安装（`pip install -r requirements.txt`）
- 端口8000是否被占用

### Q2: 向量检索报错
**解决**：
- 使用 `start_backend.bat` 启动（已配置镜像）
- 或手动设置环境变量

### Q3: Ollama未启动
**影响**：
- 本地模型不可用
- 系统会使用Mock适配器降级
- 建议启动：`ollama serve`

### Q4: 外部学习失败
**原因**：
- 未配置API密钥
- 网络问题

**解决**：
- 配置 `.env` 文件
- 检查网络连接
