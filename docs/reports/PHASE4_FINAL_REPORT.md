### 二、认知规划器 (Cognitive Planner)

**文件**: `core/services/cognitive_planner.py`

**核心能力**:
- 整合所有认知架构组件
- 完整的认知循环（感知→学习→整合→校验→进化→内省）
- 异步触发进化与评估
- 统一的系统状态管理

**认知循环流程**:
```
用户输入
    ↓
L1感知层 → L2学习层 → L3整合层 → L4校验层 → 响应
    ↓
L5进化层（异步）+ L6内省层
    ↓
记忆保存 + 关系更新 + 信号提交
```

**关键方法**:
- `process(user_input)` - 处理用户输入，返回完整结果
- `get_system_status()` - 获取系统整体状态
- `shutdown()` - 优雅关闭所有组件

## 💡 核心设计理念

### 1. 整合即统一
- 所有组件通过认知规划器统一管理
- 单一入口处理所有输入

### 2. 循环即存在
- 每次交互都是完整的认知循环
- 异步进化不阻塞响应
- 持续学习与反思

### 3. 透明即信任
- 所有处理结果可追溯
- 状态实时可查
- 组件健康度监控

## 🎓 使用示例

### 启动系统

```bash
python main_cognitive.py
```

### 交互示例

```
你: 你好，请问你是谁？

拓荒者: 我理解了你的意思。让我认真思考一下，给你一个有帮助的回应。

你: status

📊 系统状态: running
   对话数: 1
   关系: 信任=0.50

你: components

📦 组件状态:
   existence: ✅ 运行中
   gap_growth: ✅ 运行中
   proactivity: ✅ 运行中

你: exit

👋 再见！
```

### 编程接口

```python
from core.services.cognitive_planner import get_cognitive_planner

planner = get_cognitive_planner()

# 处理输入
result = planner.process("你好")
print(result.response)
print(f"成功: {result.success}")
print(f"置信度: {result.validation['confidence']}")

# 获取状态
status = planner.get_system_status()
print(f"对话数: {status['conversation_count']}")

# 关闭系统
planner.shutdown()
```
