## 核心文件清单

### 存在层模块
```
core/presence/
├── __init__.py              # 模块入口
├── existence_layer.py       # 存在层主循环
├── self_perception.py       # 自我感知模块
├── gap_growth.py           # 间隙生长引擎
└── sleep_consolidation.py  # 睡眠整合引擎
```

### 关键类和接口

**ExistenceLayer** - 存在层
- `start()` - 启动主循环
- `stop()` - 停止主循环
- `is_running()` - 检查运行状态
- `get_status()` - 获取状态信息
- `receive_signal()` - 接收外部信号

**SelfPerceptionModule** - 自我感知
- `perceive()` - 执行感知
- `update_knowledge_metrics()` - 更新知识指标
- `update_relationship_metrics()` - 更新关系指标

**GapGrowthEngine** - 间隙生长
- `submit_signal()` - 提交信号
- `get_queue_status()` - 获取队列状态
- `get_growth_summary()` - 获取生长摘要

**SleepConsolidationEngine** - 睡眠整合
- `start()` - 启动整合循环
- `stop()` - 停止整合循环
- `get_sleep_status()` - 获取睡眠状态
- `get_consolidation_summary()` - 获取整合摘要
