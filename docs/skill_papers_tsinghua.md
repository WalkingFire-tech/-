# 清华两篇Skill论文解读：从人工手写到模型自产

**来源**：清华同期在arXiv上发布两篇关于"Skill"的论文
**核心命题**：怎么让模型真正"学会学习"，而不是死记硬背
**共同结论**：两篇都把"技能"从人工手写变成了**模型自产**

---

## 第一篇：Ctx2Skill——把技能摆出来，专治长上下文的无人标注

### 核心解法：多智能体自博弈

五个冻结的 LM 智能体角色，迭代博弈：

| 角色 | 职责 |
|------|------|
| **Challenger** | 读上下文，出题（带评分细则），专挑模型不会的考 |
| **Reasoner** | 在技能引导下答题 |
| **Judge** | 中立裁判，逐条细则给二元判定，全部通过才算解出 |
| **Proposer** | 把共性的成功/失败模式综合成诊断 |
| **Generator** | 把诊断落成新的技能集 |

**关键设计**：严格对抗——失败案例路由给Reasoner侧补技能漏洞，太容易的案例路由给Challenger侧加难度，任何一方都看不到对方的技能集。

### 解决对抗崩溃：Cross-Time Replay

把每轮最难的失败题、最简单的解出题存成探针集，让每个历史技能集在探针上重评，选**难易通过率乘积最大**的那一版。乘法形式惩罚"为了难题牺牲简单题"的偏科技能集。

### 对联盟拓荒者的映射

| Ctx2Skill概念 | 系统映射 |
|--------------|----------|
| Challenger出题 | 适应度评估器发现低分场景 |
| Reasoner答题 | chat_stream 9路径并行尝试 |
| Judge判定 | 本质推理器+自我验证 |
| Proposer诊断 | 反思管道提炼教训 |
| Generator技能 | 经验池+规则库+真谛沉淀 |
| Cross-Time Replay | 棘轮门防回归 |

## 第二篇：OPID——把技能吃进去，专治RL的稀疏奖励

### 核心解法：从轨迹里回溯提取技能

把轨迹hindsight拆成两层：

| 技能层级 | 内容 | 特点 |
|----------|------|------|
| **Episode级技能** | 总结整条轨迹的全局套路 | 宽泛稳定，当默认指导 |
| **Step级技能** | 只在关键时间步捕捉局部决策 | 更精准但稀疏 |

### 关键优先路由（critical-first routing）

走到关键决策点用Step级技能，其它时候回落到Episode级技能。

### 最妙的一点

推理时什么都不用带——技能在训练阶段就把"hindsight知识"**内化进了参数**。

### 对联盟拓荒者的映射

| OPID概念 | 系统映射 |
|----------|----------|
| Episode级技能 | 战略记忆（困境-策略对） |
| Step级技能 | 程序记忆（SOP） |
| 关键优先路由 | 认知调度器根据意图类型选择记忆层 |
| 轨迹回溯 | 轨迹进化系统的revise/recombine |
| 自蒸馏优势 | 双速进化的快循环（秒级经验积累） |

---

## 对联盟拓荒者的启发

1. **技能自产**→规则库不应全靠人工编写，应从轨迹进化中自动提取
2. **对抗博弈**→多Agent协作可引入Challenger角色，主动发现系统弱点
3. **Cross-Time Replay**→棘轮门可引入探针集，确保不偏科
4. **Episode/Step分层**→分层记忆的战略/程序/工具三层与OPID的Episode/Step天然对应
5. **内化而非外挂**→经验注入应逐步沉淀为真谛，而非每次都从经验池检索
