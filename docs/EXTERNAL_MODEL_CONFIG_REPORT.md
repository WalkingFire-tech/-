## 一、实施内容

### 1. 加密存储模块 ✅

**文件**: `infrastructure/external_model_config.py`

**核心功能**:
- Fernet对称加密
- 密钥由环境变量或文件派生
- 数据库加密存储
- 前端不存储明文密钥

**关键方法**:
```python

- get_model(name)  # 获取模型（含解密）
- list_models()  # 列出模型（不含密钥）
- delete_model(name)  # 删除模型
- record_usage(name, tokens, success)  # 记录使用
- check_quota(name)  # 检查配额
- get_usage_stats(name, days)  # 获取统计
```

## 四、使用流程

### 4.1 添加模型

```
1. 点击"外脑配置"按钮
2. 点击"+ 添加新模型"
3. 填写信息:
   - 模型名称: 如 "OpenAI GPT-4"
   - API地址: 如 "https://api.openai.com"
   - API密钥: 如 "sk-..."
   - 每日配额: 如 1000
4. 点击"保存"
```

### 4.2 测试连接

```
1. 在模型列表中找到模型
2. 点击"测试"按钮
3. 系统发送测试请求
4. 显示连接结果
```

### 4.3 删除模型

```
1. 在模型列表中找到模型
2. 点击"删除"按钮
3. 确认删除
4. 模型被移除
```
