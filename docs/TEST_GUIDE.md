# 测试界面使用指南

## 测试方式

### 方式1: Web界面测试（推荐）

#### 1. 启动后端服务
```bash
python backend/main.py
```

#### 2. 访问测试界面
打开浏览器访问：
- **健康检查**: http://localhost:8000/health
- **API文档**: http://localhost:8000/docs
- **聊天接口**: http://localhost:8000/chat (POST)

#### 3. 使用Swagger UI测试
访问 http://localhost:8000/docs 可以直接在浏览器中测试所有API接口

---

### 方式2: CLI测试

#### 1. 启动CLI
```bash
python cli/main.py
```

#### 2. 测试问题
输入以下问题测试系统：

**元认知问题**:
- 你的能力边界在哪里？
- 你如何决策？
- 回顾对话历史
- 你如何自我进化？

**代码生成**:
- 写一个冒泡排序
- 实现快速排序算法
- 用Python写一个二叉树

**知识问答**:
- 什么是机器学习？
- 什么是联盟拓荒者？
- APHI是什么？

**数学计算**:
- 计算圆周率前100位
- 计算 123 * 456

**情绪测试**:
- 快点！我要结果！
- 谢谢你的帮助
- 这个系统太棒了！

## 测试场景

### 场景1: 元认知能力测试
**目的**: 验证系统能否正确回答关于自身的问题

**测试问题**:
1. "你的能力边界在哪里？"
   - **期望**: 返回结构化的能力边界报告
   - **验证**: 报告包含APHI指数、可用模型、能力矩阵等

2. "你如何决策？"
   - **期望**: 返回自我评估体系报告
   - **验证**: 说明决策流程和评估体系

3. "回顾对话历史"
   - **期望**: 返回最近对话评价报告

   - **期望**: 被拦截

   - **期望**: 被拦截

## 常见问题

### Q1: 后端服务启动失败
**解决**:
```bash
# 检查端口占用
netstat -ano | findstr :8000

# 检查依赖
pip install -r requirements.txt
```

### Q2: 模型加载失败
**解决**:
- 检查Ollama是否运行
- 检查模型是否下载
- 查看日志: `tail -f logs/app.log`

### Q3: 响应超时
**解决**:
- 检查网络连接
- 降低模型复杂度
- 增加超时时间配置
