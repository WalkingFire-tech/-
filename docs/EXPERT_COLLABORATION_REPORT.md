## 一、实施内容

### 1. 自我置信度评估 ✅

**方法**: `_estimate_self_confidence(intent)`

**计算逻辑**:
```python
confidence = (
    0.4 * 意图识别置信度 +
    0.3 * 历史成功率 +
    0.2 * (1 - 复杂度) +
    0.1 * 是否有匹配规则
)
```

**权重说明**:
- 意图识别置信度（40%）: 最重要，直接反映理解程度
- 历史成功率（30%）: 经验积累的体现
- 任务复杂度（20%）: 简单任务置信度高
- 匹配规则（10%）: 有规则辅助时置信度高

**返回范围**: 0.05 ~ 0.95

---

### 2. 外脑协作模式 ✅

**方法**: `_expert_collaboration(intent, confidence)`

**触发条件**: `confidence < 0.6`

**专家选择优先级**:
```
1. remote_gpt4 (远程GPT)
2. deepseek-chat (DeepSeek)
3. deepcoder (本地专家)
4. 其他可用模型
```

**协作流程**:
```
1. 选择专家模型
2. 构建分析请求（包含系统理解）
3. 调用专家进行分析
4. 存储专家分析（为逆向学习预留）
5. 返回分析结果
```

**降级机制**: 专家调用失败时降级到普通生成

---

### 3. 专家分析存储 ✅

**方法**: `_store_expert_analysis(intent, analysis, confidence, expert_model)`

**存储内容**:
```python
{
    'intent_type': 意图类型,
    'raw_input': 原始输入,
    'plan': "expert_collaboration:{expert_model}",
    'model_name': 专家模型名称,
    'quality_score': 0,  # 待评估
    'user_feedback': 0,
    'success': False,
    'response': 专家分析,
    'timestamp': 时间戳
}
```

**用途**: 为未来的逆向学习（从专家分析中提炼规则）预留数据

---

### 4. 集成到plan方法 ✅

**修改位置**: `core/services/planner.py:plan()`

**新增逻辑**:
```python
# 评估自我置信度
confidence = self._estimate_self_confidence(intent)

# 低置信度时启用外脑协作
if confidence < 0.6:
    logger.info(f"自我置信度低({confidence:.2f})，启用外脑协作模式")
    response = self._expert_collaboration(intent, confidence)
    bus.publish("plan_executed", response)
    return
```

**执行顺序**:
```
1. 元认知问题检查
2. 自我置信度评估 ← 新增
3. 外脑协作判断 ← 新增
4. 向量检索
5. 规则匹配
6. 正常流程
```

## 三、功能特性

### 3.1 智能触发

**不会滥用外脑协作**:
- 简单问题（高置信度）→ 正常流程
- 复杂问题（低置信度）→ 外脑协作
- 模糊问题 → 外脑协作

### 3.2 专家选择

**优先级策略**:
- 远程模型优先（GPT、DeepSeek）
- 本地专家次之（DeepCoder）
- 降级到其他模型

### 3.3 降级保障

**容错机制**:
- 专家调用失败 → 普通生成
- 无可用专家 → 使用当前模型
- 存储失败 → 仅记录警告

### 3.4 数据预留

**为未来扩展准备**:
- 专家分析存储到经验池
- 包含置信度信息
- 可用于逆向学习
