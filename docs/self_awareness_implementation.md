# 自我认知能力实现总结

## 核心理念

> **"先让它学会照镜子，再让它选择穿什么衣服"**

系统必须先能够清晰地回答"我是谁、我知道什么、我哪里还不行"，才有资格去思考"我应该变成什么样"。

---

## 已实现的核心模块

### 1. 决策链记录系统 (DecisionChain)

**文件**: `core/decision_chain.py`

**功能**:
- 记录L1-L5每一层的关键输入输出
- 生成可读的决策链文本
- 支持历史查询和统计

**命令**:
```
:why              - 显示上次决策的完整推理路径
:why detailed     - 显示详细信息
:why <id>         - 显示指定ID的决策链
:stats            - 显示决策链统计
:history          - 显示决策链历史
```

**示例输出**:
```
======================================================================
  决策链 #20260623_012027
  创建时间: 2026-06-23T01:20:27
======================================================================

【步骤1】L1 - 感知层
  时间: 2026-06-23T01:20:27
  置信度: 0.90
  推理: 关键词匹配: '什么是', 'AI'

【步骤2】L2 - 理解层
  时间: 2026-06-23T01:20:27
  置信度: 0.85
  推理: 事实性问题，需要客观知识

【步骤3】L3 - 推理层
  时间: 2026-06-23T01:20:27
  置信度: 0.80
  推理: 从事实库检索到定义

======================================================================
  最终输出: AI是人工智能，是计算机科学的一个分支。
  最终置信度: 0.85
======================================================================
```

### 2. 学习反思引擎 (LearningReflector)

**文件**: `core/learning_reflector.py`

**功能**:
- 记录学习事件（注入、纠错、外部学习等）
- 反思单次学习事件的效果
- 生成学习报告（日/周/月）
- 识别优势和劣势
- 提出改进建议

**命令**:
```
:reflect          - 反思最近一周的学习
:reflect day      - 反思最近一天
:reflect month    - 反思最近一月
```

**示例输出**:
```
======================================================================
  学习反思报告 (day)
  生成时间: 2026-06-23T01:20:27
======================================================================

【总体统计】
  总学习事件: 6
  成功率: 50.0%
  平均改进: 20.0 分

【知识状态】
  ✅ 已吸收: 3
  ⏳ 待验证: 3
  ❌ 已拒绝: 0

【优势】
  💪 external_learn成功率高(100%)
  💪 平均改进幅度大(20.0分)

【建议】
  1. 学习状态良好，继续保持
======================================================================
```

### 3. 能力缺口诊断器 (CapabilityGapDiagnoser)

**文件**: `core/capability_gap_diagnoser.py`

**功能**:
- 统计未能回答的问题类型
- 按类别聚类（视觉类、专业类、事实类等）
- 识别用户行为中的隐含需求
- 映射到"感官模块库"中的可用模块
- 生成"能力缺口报告"

**支持的缺口类型**:
- **visual** - 视觉处理 → 视觉模块
- **audio** - 语音处理 → 语音模块
- **code** - 代码执行 → 代码执行模块
- **math** - 数学计算 → 数学计算模块
- **knowledge** - 知识问答 → 知识库扩展
- **recommendation** - 推荐建议 → 推荐引擎
- **external_data** - 外部数据 → 实时数据模块

**示例输出**:
```
======================================================================
  能力缺口诊断报告 (day)
======================================================================

【交互统计】
  总交互数: 28
  失败交互: 24
  失败率: 85.7%

【能力缺口】(按优先级排序)

  1. 视觉处理 [★★★★★]
     频率: 8 次
     严重度: 80.0%
     建议模块: 视觉模块 (Vision Module)

  2. 语音处理 [★★★]
     频率: 4 次
     建议模块: 语音模块 (Audio Module)

【改进建议】
  【紧急】添加 视觉模块 (Vision Module) - 视觉处理失败8次
  【建议】考虑添加 语音模块 (Audio Module) - 语音处理失败4次
======================================================================
```

```
:stats            - 显示决策链统计

```

## 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                    用户输入                                  │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  【L1-L5 认知层级】每一步都记录到决策链                        │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  【决策链】记录输入、输出、推理、置信度                        │
│  - 可视化推理路径                                            │
│  - 支持历史查询                                              │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  【学习反思】记录学习事件，评估效果                           │
│  - 成功率统计                                                │
│  - 优势劣势识别                                              │
│  - 改进建议生成                                              │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  【能力缺口诊断】识别系统无法处理的问题类型                    │
│  - 按类型聚类                                                │
│  - 计算优先级                                                │
│  - 映射到感官模块                                            │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  【模块添加建议】生成供人工审阅的建议                          │
└─────────────────────────────────────────────────────────────┘
```
