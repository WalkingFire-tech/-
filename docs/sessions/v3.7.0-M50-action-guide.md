## Discoveries

### M50新发现
- **`_select_model`函数不存在** — chat_handler.py中的模型选择函数实际名为`_get_available_ollama_model()`，不是`_select_model()`
- **精神内核矛盾对误判** — "不能/能"和"否/是"在中文中经常同时出现但不矛盾（如"不能说一定能"），需按句子级别检测
- **【】括号匹配错误** — cognitive_bottleneck.py中`【([^】]+)」`应为`【([^】]+)】`

### 历史发现
- `socket.socketpair()` 在Windows sandbox中失败，导致uvicorn `--reload`不可用
- PowerShell的`curl`是`Invoke-WebRequest`的别名
- f-string中不能在格式说明符内使用条件表达式
- `signal.SIGALRM`在Windows上不存在
- 服务器启动需要约5-8秒（向量检索器加载耗时）
- `long_term_memory.py`连接的是独立的`long_term_memory.db`，与`stereo_memory.db`不冲突
- 数据库表名：stereo_memories（不是memories）、learning_rules（正确）
- `/api/chat`非流式端点走的是`chat_handler.py`的`chat_never_giveup`，不走9路径并行流程
- `chat_handler.py`和`chat_stream.py`各有独立的`_save_to_experience_pool`函数，需分别维护
- `world_model.predict()`期望Dict不是str，需传`{"entity": x, "intent": y}`
- GPU过热关机根因：BIOS热保护阈值异常低(21°C)，需8层动态节流
- `resource_awareness`模块不断触发reload循环（watchfiles检测到变化），需用不带`--reload`方式启动
