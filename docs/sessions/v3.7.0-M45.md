### GPU/硬件相关指令（本次会话新增，非常重要）
- **不能因为硬件有问题就降级或直接不执行** — 必须动态调整策略，放缓而非禁止
- **GPU热了就放缓节奏，先走外部API，等GPU凉了再回来补本地推理**
- **冷却不应强制执行** — 应动态调整，执行过程中发现硬件太热就适当放缓
- **本地模型+外部模型同步执行协作运行更稳妥**
- **如果配置的外部模型足够多，可以考虑很多模型并行执行**
- **关机可能发生在回复之后的后台学习阶段**，不是回复生成时

## Discoveries

### 电脑反复自动关机问题（本次会话核心问题）
- **7月3-5日共8+次意外关机**（EventID 6008），全部是EventID 41（非正常关机）
- **无MEMORY.DMP、无BSOD** → 不是蓝屏，是直接断电
- **每次都发生在AI生成长回复后** → GPU持续满载是触发条件
- **关键洞察（用户提供）**：关机可能不是在回复生成时，而是在回复后的后台学习阶段
- **根因确认**：回复发出后，系统触发3个后台Ollama调用（`_bg_auto_evolution`、`_do_deep_thinking`、`_do_model_review`），GPU刚完成推理还在高温，紧接着后台又启动Ollama → 持续满载 → 过热断电
- **ACPI热区域**：`_CRT=294K(21°C)`、`_HOT=293K(20°C)` — BIOS热保护阈值异常低
- **硬件**：AMD Ryzen 5 3600X + 32GB RAM + RX 580 8GB VRAM，3个本地Ollama模型 + 外部API

### GPU监控能力
- `pyadl`库可读取AMD GPU温度/频率/电压/使用率/风扇
- 当前GPU空闲：51°C / 使用率1%
- psutil可读取CPU/内存/磁盘
- WMI可读取ACPI热区温度

### 响应组装Bug（本次会话发现）
- **症状**：系统从DeepSeek/经验池获得了好结果（评分105），但最终输出是"🎯 关于「」我已穷尽2种方法"的失败模板
- **根因**：`metacognitive_executor.py`第744行在所有任务失败时调用`spirit_core.ensure_meaningful_response("", attempts)`生成失败模板，`_do_deep_thinking`将此结果通过`self._save_experience(query, result)`保存到经验池，后续查询时被检索出来作为candidate
- **修复**：在`_save_experience`前检查结果是否为失败模板（"我已穷尽"不在结果中）

### 其他技术发现
- `socket.socketpair()`在Windows sandbox中失败，导致uvicorn `--reload`不可用
- PowerShell的`curl`是`Invoke-WebRequest`的别名
- f-string中不能在格式说明符内使用条件表达式
- `signal.SIGALRM`在Windows上不存在
- 服务器启动需要约5-8秒（向量检索器加载耗时）

### M46: spirit_core验证粒度提升 ✅

- **增强为8维度验证**，对应8条核心原则：
  1. 有意义回复（非空非敷衍）

  3. 逻辑自洽（无自相矛盾）

  5. 状态同步（回复不是终结而是状态）
  6. 追求本质（不满足于表面答案）
  7. 困惑时坦诚（不强行融合矛盾）
  8. 多源验证（不依赖单一来源）
- **新增返回字段**：`checks`（各维度通过/未通过）、`score`（0-1合规分数）
- **新增`VALIDATION_DIMENSIONS`类常量**：维度名称映射
- **`get_spirit_status()`**更新：包含全部8条核心原则+验证维度信息
