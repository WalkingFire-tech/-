## Gotchas（真实踩坑记录）

### 环境
| 场景 | 禁止行为 | 正确做法 |
|------|----------|----------|
| Windows启动uvicorn | 不要用--reload | socket.socketpair()在Windows sandbox中失败 |
| PowerShell调用curl | 不要直接用curl | 是Invoke-WebRequest的别名 |
| f-string格式化 | 不要在格式说明符内用条件表达式 | 先算好值再格式化 |
| Windows信号处理 | 不要用signal.SIGALRM | 不存在，用threading.Timer |
| Start-Process | 不要假设一定成功 | sandbox中有时不成功，用-PassThru确认PID |

### 数据库
| 场景 | 禁止行为 | 正确做法 |
|------|----------|----------|
| stereo_memory表名 | 不要用memories | 表名是stereo_memories |
| world_model数据库锁 | 不要在conn内嵌套开新conn | _update_edge_confidence_in_conn中不能再开新conn |
| 经验池_save_to_experience_pool | 不要假设只有一份 | chat_handler.py和chat_stream.py各有独立副本 |
| 中英文匹配 | 不要直接比较中文意图和英文边类型 | 用cn_to_en映射：成功↔success |

### 架构
| 场景 | 禁止行为 | 正确做法 |
|------|----------|----------|
| /api/chat非流式端点 | 不要以为它走9路径并行 | 它走chat_never_giveup，需单独添加外部API |
| CBNR L3输入 | 不要给L3传空causal_chain | 从cbnr_context获取L2的reconstructed_output |
| world_model.predict() | 不要传字符串作为current_state | 期望Dict，传{"entity": x, "intent": y} |
| spirit_core在函数内import | 不要`from ... import spirit_core` | 会污染局部命名空间，用`import as _spirit_core` |
| 贡献归因格式化 | 不要对None值用:.0% | 添加`if v is not None`过滤 |
| 精神教训lessons | 不要用`lessons[:100]` | 那是列表切片100个元素，用`str(lessons)[:200]` |
| cbnr_context检查 | 不要用`'cbnr_context' in dir()` | 用try/except更安全 |
