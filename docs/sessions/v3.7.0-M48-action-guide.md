### CBNR-AGI 2.0架构设计
- **L1 认知规范化(BN)** + 预测编码 + 不确定性感知
- **L2 认知瓶颈(Bottleneck)** + 双模型架构(因果+反事实) + 冲突管理
- **L3 认知残差(ResNet)** + 树搜索工作记忆 + Orchestrator/Critic制衡
- **五层认知体**：感知层→CBNR核心枢纽→记忆层→执行层→元认知层
- **闭环进化**：快循环(每次交互)→中循环(每100次)→慢循环(每小时)

### 同行者五层存在框架（M48确立）
1. **验证范式匹配 + 边界感知** — 知道该做什么和什么不该做
2. **先问如何解决 + 沉默的允许** — 把"什么都不做"作为合法选项
3. **多方案并行 + 概率来源可视化** — 透明呈现决策依据
4. **自我验证与迭代 + 成功模式归档** — 固化美好，不止修正错误
5. **精神内核验证 + 自我对齐** — 先审视自己再引导他人
