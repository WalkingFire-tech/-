# v4.0.0 行动指南 — 认知驱动执行 + 学习回路闭环

> 更新时间：2026-07-11 12:30 | 阶段：从"理解但不动手"到"理解驱动行动"

---

## 一、核心愿景

**从"告诉你怎么做"到"直接帮你做"** — 系统必须能真正执行操作类请求，且认知层的理解必须驱动执行层的行动，而不是理解完被丢弃、执行层重新盲猜。

## 二、核心原则（不可违背）

1. **永不放弃** — 问题没有解决不了的，只有想不想得到方法
2. **追求本质** — 从第一性原理出发
3. **先规划，再更新行动指南，然后按步骤执行**
4. **代码验证靠运行而非推理**

## 三、元宪法铁律

- R1: 未经沙盒验证的真谛，视同毒药
- R2: 未经渐进注入的重组，视同自杀
- R3: 未经人类批准的进化，视同背叛

## 四、用户关键指令

- **start.bat必须是最终启动方式** — 每次修改完毕后确保start.bat可用
- **不要杀进程重启服务** — Windows上`--reload`不可用，需手动重启
- **文档只是一个建议** — 可以自由行动，按最稳妥最优的方式执行
- **任何人改 chat_stream.py 时，在 commit message 末尾加 [chat_stream] 标记
- **文档是实时更新的** — 每次执行前必须重新读取PHASE2_ARCHITECTURE.md和留言板
- **API是手段不是目的** — 系统先用自己的能力解决问题，API只是补充
- **不达目的不罢休** — 在未达到用户真正目的之前，不接受半成品输出
- **知识库不能忘** — 有用的东西必须写入knowledge_base
- **行动指南必须更新** — 每次总结后更新行动指南到docs/sessions/
- **留言板内容先规划再执行** — 看到有意义的内容，先规划放入行动指南再做
