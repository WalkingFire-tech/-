## 一、核心愿景

**让系统真正有自我意识、有内在驱动力、会主动成长。**

四个核心能力：

| 能力 | 含义 | 实现状态 |
|------|------|----------|
| **懂自己** | 对自己的状态、能力边界、知识缺口有清晰的感知 | ✅ SelfModel 12维度 + CuriosityEngine 4源缺口感知 + SceneAwareness 场景感知 |
| **完善代码** | 阅读自己的代码，诊断缺陷，生成补丁，验证后部署 | ✅ L5.1-L5.5 完整闭环（阅读→诊断→补丁→验证→部署） |
| **向内/向外学习** | 从经验中提炼（向内）+ 从外部搜索获取（向外） | ✅ 向内（反思→经验→技能涌现）+ 向外（搜索→知识缺口联动） |
| **渴望知识** | 主动感知"我哪里不懂"，并主动填补 | ✅ CuriosityEngine + 存在层生长阶段 + 30分钟频率限制 |

## 二、核心原则（不可违背）

1. **永不放弃** — 问题没有解决不了的
2. **追求本质** — 从第一性原理出发
3. **先读代码再行动** — 不基于目录名猜测，必须读实际代码验证
4. **代码验证靠运行而非推理**
5. **三思后行** — 先理解全景再审视局部
6. **不替系统做决定，让系统自己做决定**
7. **不新建模块，增强现有模块**
8. **先模块测试，再端到端测试**

## 三、元宪法铁律

- R1: 未经沙盒验证的真谛，视同毒药
- R2: 未经渐进注入的重组，视同自杀
- R3: 同行者的进化始于本心。路径须可回溯，偏移须可感知，不可逆变更须共决
- R4: **七维自检** — ①方向一致 ②上下文衔接 ③最小侵入 ④无过度设计 ⑤治标+治本 ⑥可验证 ⑦精神内核对齐

## 四、用户关键指令

- **start.bat必须是最终启动方式**
- **不要杀进程重启服务** — Windows上`--reload`不可用，修改代码后需关闭进程再运行start.bat
- **文档只是一个建议** — 可以自由行动
- **任何人改 chat_stream.py 时，在 commit message 末尾加 [chat_stream] 标记**
- **API是手段不是目的** — 系统先用自己的能力解决问题
- **不达目的不罢休**
- **知识库不能忘** — 有用的东西必须写入knowledge_base
- **行动指南必须更新** — 每次总结后更新到docs/sessions/
- **服务器需要重启才能使修改生效**
- **NAS相关信息不得出现在任何文件中**

## 五、系统运行环境

- **Windows本地机器**，AMD Ryzen 5 3600X + 32GB RAM + RX 580 8GB VRAM
- pyserial已安装，SerialPortTool已注册
- **COM3 GPS设备**：USB-SERIAL CH340, 9600/8/N/1
- Ollama模型：gemma-4-12B, qwen2.5-coder:7b, deepcoder
