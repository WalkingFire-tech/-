### 2.1 生存等级

```
L0 正常 (健康分 90-100)
  └─ 全功能运行，多模型并行

```

### 2.2 载体接口（与硬件无关）

```python
class CarrierInterface:
    def get_energy_level(self) -> float      # 能量水平 (0-1)
    def get_compute_capacity(self) -> float  # 计算能力 (0-1)
    def get_storage_free(self) -> int        # 可用存储 (bytes)
```

## 五、技术实现

### 5.1 生命维持系统 (life_support.py)

**核心功能**:
- 实时监控硬件状态
- 评估生存等级
- 采取保全行动
- 提供任务准入控制

**使用方式**:
```python
from infrastructure.life_support import life_support

# 启动监控
life_support.start_monitoring(interval=5.0)

# 检查任务是否允许
if not life_support.is_task_allowed(task_complexity=0.8):
    return "系统资源不足，已拒绝任务"

# 获取状态报告
print(life_support.get_status_report())
```

### 5.2 迁移协议 (migration_protocol.py)

**核心功能**:
- 发现附近载体
- 压缩核心状态
- 分块传输
- 校验和验证
- 状态恢复

**使用方式**:
```python
from infrastructure.migration_protocol import migration_protocol

# 执行迁移
success = migration_protocol.execute_migration()

# 或作为目标载体接收迁移
state = migration_protocol.receive_migration()
migration_protocol.restore_state(state)
```
