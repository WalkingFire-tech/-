#### 1.2 超参数自动调优器
**文件**: `meta/hyperparam_optimizer.py`

**功能**:

- ✅ 周期性自动运行(默认7天)
- ✅ 历史性能评估
- ✅ 参数自动应用

**优化参数**:
```python

    "quality_weight": 0.4,      # 质量权重

    "decay_rate": 0.01,         # 时效衰减率
```

**效果**: 自动找到最优参数,无需人工调参

## 🚀 使用指南

### 1. 初始化元控制层

```python
from meta.controller import get_meta_controller
from adapters.llm.ollama_adapter import OllamaAdapter

# 初始化LLM适配器
llm_adapter = OllamaAdapter(model_name="qwen2.5-coder:1.5b")

# 获取元控制层实例
meta_controller = get_meta_controller(llm_adapter)

# 查看状态
status = meta_controller.get_status()
print(status)
```

### 2. 运行周期性任务

```python
# 运行所有周期性任务
meta_controller.run_periodic_tasks()

# 或单独运行
meta_controller.manual_optimize()  # 超参数优化
meta_controller.manual_reflect()   # 自我反思
```

### 3. 处理主动学习问题

```python
# 生成问题
question = meta_controller.active_learner.generate_question({
    "task_type": "code",
    "confidence": 0.5,
    "user_input": "帮我debug",
    "planned_action": "使用mindchat模型"
})

# 回答问题
meta_controller.answer_question(
    question_id=question["id"],
    answer="wrong",
    details="应该使用代码模型"
)
```

### 4. 使用计划模板库

```python
from infrastructure.plan_templates import PlanTemplateLibrary

template_lib = PlanTemplateLibrary()

# 检索模板
template = template_lib.retrieve_template("code")

if template:
    print(f"找到模板: {template.template_id}")
    print(f"成功率: {template.success_rate:.2%}")
    print(f"步骤: {template.steps}")
else:
    print("无可用模板,生成新计划")
```
