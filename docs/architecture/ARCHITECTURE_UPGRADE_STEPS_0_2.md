### 步骤2：工具仲裁器（30分钟）

**创建文件**：
- `tools/arbiter.py` - 工具仲裁器（UCB1算法）

**算法**：
```
UCB1分数 = 成功率 + sqrt(2 * ln(N) / n)

其中：
- N = 总调用次数
- n = 该工具调用次数

自动平衡：
- 成功率高的工具（利用）
- 尝试次数少的工具（探索）
```
