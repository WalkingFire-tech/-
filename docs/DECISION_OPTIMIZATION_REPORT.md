## 核心理念

**从"模型中心主义"到"系统智能主义"**

```
传统思维: 模型能力不足 → 换更大模型 → 成本高、不可持续
系统思维: 模型能力不足 → 激活元能力 → 自我进化、可持续
```

---

## 五层防御机制

### 第1层：工具优先调用 ✅
**文件**: `core/services/planner.py:1125-1130`

**触发条件**: 意图类型匹配工具类别

**流程**:
```
用户问题 → 意图识别 → 查找工具 → 执行工具 → 返回结果
```

**示例**:
- 用户: "π的前100位是什么？"
- 系统: 调用 `math_calculator.get_constant('pi', 100)` → 直接返回精确值
- **不再依赖模型生成**

---

### 第2层：任务智能分解 ✅
**文件**: 已有 `task_decomposer.py` + `result_fusion.py`

**触发条件**: 任务复杂度高 或 置信度 < 0.6

**流程**:
```
复杂问题 → 分解子任务 → 并行调度多模型 → 结果融合 → 返回
```

**示例**:
- 用户: "分析Python和Go的并发模型，并写代码演示"
- 系统: 分解 → [分析模型] + [写代码] → 融合 → 完整答案

---

### 第3层：知识库检索 ✅
**文件**: `infrastructure/knowledge_injector.py`

**触发条件**: 问题在知识库中有记录

**流程**:
```
用户问题 → 哈希查找 → 返回历史答案 → 置信度随访问提升
```

**核心能力**:
- `inject_knowledge()`: 注入正确答案（从失败中学习）
- `retrieve_knowledge()`: 检索历史答案（经验复用）
- `search_similar()`: 模糊匹配相似问题
- `update_quality()`: 用户反馈更新质量

**示例**:
- 用户: "2024年诺贝尔物理学奖得主是谁？"
- 模型: 不知道
- 用户: ":teach 2024年诺贝尔物理学奖授予了..."
- 系统: 注入知识库 → 下次直接返回

---

### 第4层：主动向用户求助 ✅
**文件**: `core/services/planner.py:1450-1495`

**触发条件**: 连续失败 ≥ 2次

**流程**:
```
失败检测 → 生成求助消息 → 提供帮助途径 → 等待用户响应
```

**求助消息示例**:
```
抱歉，我在处理这个问题时遇到了困难。

**您可以通过以下方式帮助我**：
1. 📝 提供答案 - :teach <答案>
2. 🔍 授权搜索 - :enable web_search
3. 🔄 换种问法
4. 📊 查看能力边界
```

### 第5层：失败学习机制 ✅

## 集成到主流程

**文件**: `core/services/planner.py:plan()`

**完整流程**:
```python
def plan(intent):
    # 0. 健康度检查
    if health_dashboard.should_reduce_load():
        return "系统状态不佳..."
    
    # 0. 资源检查
    if not resource_check.within_limits:
        return "资源紧张..."
    
    # 特殊: 元认知问题
    if intent.type == "meta":
        return _handle_meta_question()
    
    # 【第1层】工具优先
    if tool_result := _try_tool_first(intent):
        return tool_result
    
    # 【第3层】知识库检索
    if knowledge := _try_knowledge_retrieval(intent):
        return knowledge
    
    # 评估置信度
    confidence = _estimate_self_confidence(intent)
    
    # 【第2层】低置信度 → 外脑协作
    if confidence < 0.6:
        return _expert_collaboration()
    
    # 【第2层】复杂任务 → 分解
    if is_complex_task(intent):
        return _decompose_and_execute()
    
    # 正常模型调用
    try:
        response = model.generate()
        # 反事实模拟（异步）
        counterfactual_simulator.simulate()
        return response
    except:
        # 【第4层】主动求助
        if help_msg := _request_user_help():
            return help_msg
        
        # 【第5层】失败学习
        _trigger_failure_learning()
```

**联盟拓荒者已从"依赖模型"进化为"系统智能"**

1. ✅ 优先调用工具（精确答案）

4. ✅ 主动向用户求助（透明协作）
5. ✅ 从失败中学习（自我进化）

**局限性不是系统的终点，而是进化的起点。** 🔥
