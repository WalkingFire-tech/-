---

### 2. 版本控制事实存储

**文件**: `infrastructure/versioned_fact_store.py`

**核心类**: `VersionedFactStore`

**核心方法**:

| 方法 | 功能 | 返回值 |
|------|------|--------|
| `add_assertion()` | 添加断言（自动处理冲突） | (id, action) |
| `get_active_assertions()` | 获取当前有效断言 | List[Dict] |
| `get_assertion_history()` | 获取历史版本 | List[Dict] |
| `rollback_to_version()` | 回滚到指定版本 | bool |
| `get_statistics()` | 获取统计信息 | Dict |

**冲突解决策略**:
- `user` - 用户纠错永远优先
- `confidence` - 置信度高的优先
- `keep` - 保留旧版本
