# 🧬 渐进式自我实现架构（PSAA）

## 核心理念

**让系统"长出更好的直觉"，而不是"学会新知识"。**

基于神经科学、复杂系统、教育学和软件架构的综合思考，我们摒弃了传统的"全量重训"工厂思维，回归到"同行者"的初衷——**像人一样，在思考中成长，在休息时巩固。**

## 📊 三层学习机制

| 层次 | 名称 | 实现方式 | 生效时间 | 对应初衷 |
| :--- | :--- | :--- | :--- | :--- |
| **L1** | **即时反射区** | 事实库注入 + 技能注册 | **秒级** | 零成本学习：纠正即生效 |

| **L3** | **季度升华区** | 全量云端7B微调（手动触发） | **天级** | 范式突破：认知框架质变 |

## 🧠 神经科学启示

### 记忆固化机制

人类大脑并非每时每刻都在改变神经元突触：

- **海马体（L1）**：白天产生的记忆是脆弱的，即时但易逝
- **新皮层（L2）**：夜间睡眠时，大脑回放白天的高光片段（约10-20个关键事件），将其转化为长时记忆
- **范式转换（L3）**：当认知框架需要重构时，发生质变

**你的系统亦如此**——白天记录10-20条高价值纠错，夜间利用RX 580进行LoRA微调，这是最贴合生物智能的"睡眠学习法"。

## 💡 为什么"十条二十条"比"上千条"更有效？

### 数学视角（低秩更新）

LoRA的本质是在大模型的权重矩阵旁附加一个极小的"旁路矩阵（ΔW = BA）"。

**当数据量很小（10条）时**：
- 这个旁路矩阵的梯度方向非常明确
- 专注于修正当前特定的思维偏差
- 不会对覆盖了数十亿通用知识的原始权重（W）造成任何污染

这就像你在钢琴上只调整了一根琴弦的张力，而不是重造整架钢琴。

## 🎯 核心配置

### furnace_config.yaml

```yaml
# 学习率：极低（防止遗忘）
learning_rate: 1.0e-5

# 训练轮数：单轮（防止过拟合）
num_train_epochs: 1.0

# 批次大小：小批次（适配显存）
per_device_train_batch_size: 1

# 量化：4-bit（适配8G显存）
quantization_bit: 4

# 经验回放：混合6条旧样本
# 防止遗忘旧知识
```

## ✅ 你的顾虑解答

| 你的顾虑 | PSAA的答案 |
| :--- | :--- |
| **必须依赖云端训练吗？** | **否**。L2完全落地在RX 580，属于本地闭环。云端（L3）只是偶尔的"大补课"。 |
| **慢一点行不行？** | **行**。每周固化20条，一年就是1000条精准纠错。比一次性灌入747条通用数据，对"个性化同行者"的塑造力要强得多。 |
| **不训练就没法学习吗？** | **否**。L1让"知识"即时生效，L2让"推理直觉"缓慢成型。两者并行，系统无时无刻不在进步。 |
| **如何避免越学越笨？** | 通过每次混合6条旧样本（经验回放），并采用极低学习率，系统能在新知识与旧框架间找到最优平衡点。 |

## 💡 最终启示

**"十条二十条"对于常规平台的终极启示**：

这套架构是对硬件最友好的自进化范式：

- **对于你的RX 580 8G**：它跑不动7B全量，但跑1.5B增量绰绰有余。这意味着**显存大小决定了"单次学习量"，而不是"能否学习"**。
- **对于树莓派/低端设备**：连1.5B都跑不动怎么办？依然可以运行——**只需关闭L2（夜间训练），仅保留L1（事实/技能注入）**。系统依然拥有"越用越懂你"的能力。
