## 设计理念

### 评估即驱动
- 底层评估体系的目的不是"衡量"，而是"驱动"
- 所有指标都形成闭环：评估 → 决策 → 执行 → 再评估

### 三大协同机制
1. **可反馈**: 评估结果反馈到决策模块
2. **可行动**: 指标映射到具体调整动作
3. **长期对齐**: 优化方向与系统终极目标一致
