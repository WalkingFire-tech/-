## 主流程功能

### 处理问题流程

```
1. L1感知层 - 意图识别
2. L2理解层 - 知识检索
3. L3推理层 - 回答生成
4. L4校验层 - 质量评估
5. 元认知循环 - 自我复盘+老师评估
6. 知识注入 - 低分时触发
```

### 支持的命令

```
:stats   - 显示系统统计
:why     - 显示决策链
:reflect - 显示反思报告
:export  - 导出训练数据
:help    - 显示帮助
exit     - 退出系统
```

### 反馈处理

- **点赞** - 记录正面反馈
- **点踩** - 记录负面反馈
- **纠错** - 更新事实库，触发验证
- **跳过** - 不记录反馈
