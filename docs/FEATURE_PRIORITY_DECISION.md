## 二、最优决策

### 决策：优先实施外脑配置管理面板（P0）

**理由**：
1. **安全风险最高** - API密钥明文存储存在泄露风险
2. **功能依赖** - 刚实现的外脑协作需要配置界面支撑
3. **成本控制** - 无配额限制可能导致高额费用
4. **用户体验** - 手动配置方式严重影响可用性

### Git推送按钮延后到P1（本周）

**理由**：
1. 系统刚稳定，暂不急需频繁发布
2. 实施复杂度较高，需要充分测试
3. 候选版本模式设计合理，但需要社区活跃后再实施

## 三、实施计划

### 立即实施（今天）：外脑配置管理面板

#### 核心功能

1. **加密存储** ✅
   - 使用Fernet对称加密
   - 密钥由环境变量派生
   - 前端不存储明文密钥

2. **API端点** ✅
   - GET /api/external_models - 列出模型
   - POST /api/external_models - 添加模型
   - DELETE /api/external_models/{name} - 删除模型
   - POST /api/external_models/test - 测试连接

3. **前端界面** ✅
   - 侧边栏配置按钮
   - 模态框展示模型列表
   - 添加/删除/测试功能

4. **配额控制** ✅
   - 每日调用限制
   - 使用量统计
   - 超额自动禁用

5. **安全防护** ✅
   - 前端不展示明文密钥
   - 后端加密存储
   - 审计日志记录

#### 实施步骤

```
步骤1: 创建加密配置模块 (infrastructure/external_model_config.py)
步骤2: 添加后端API端点 (backend/main.py)
步骤3: 创建前端界面组件 (frontend/)
步骤4: 集成配额控制
步骤5: 测试验证
```

---

### 本周实施（P1）：Git推送快捷按钮

#### 核心功能

1. **候选版本模式**
   - 运行测试套件
   - 生成变更日志
   - 创建Git分支
   - 提交并推送
   - 创建Pull Request

2. **安全机制**
   - 测试失败则中止
   - PR模式保留审查
   - 变更摘要自动生成

3. **用户引导**
   - 展示PR链接
   - 配置GitHub Token
   - 权限说明
