```python
class BayesianOptimizer:
    def define_objective_function(eval_function)  # 定义目标函数
    def optimize(params, n_iterations, method)    # 执行优化
    def apply_best_params(best_params)           # 应用最佳参数
    def save_optimization_result(result)         # 保存结果
    def get_param_suggestions()                  # 获取参数建议
```

**优化参数**:
- `quality_weight`: 质量权重 (0.0-1.0)
- `speed_weight`: 速度权重 (0.0-1.0)
- `cost_weight`: 成本权重 (0.0-1.0)
- `quality_threshold`: 质量阈值 (0-100)
- `confidence_threshold`: 置信度阈值 (0.0-1.0)
- `fallback_retry`: 重试次数 (1-5)

## 🔄 工作流程

### 优化流程

```
定期触发(每周)
  ↓
加载历史数据(7天)
  ↓
定义目标函数(最大化质量分)
  ↓
执行贝叶斯优化
  ↓
评估参数组合
  ↓
选择最佳参数
  ↓
人工确认
  ↓
应用到配置
```

### 归纳流程

```
定期触发(每周)
  ↓
加载经验数据(7天)
  ↓
挖掘模式(意图/模型/质量)
  ↓
生成规则(条件→动作)
  ↓
保存到规则库(pending)
  ↓
人工审核
  ↓
激活生效
```

### 冲突检测流程

```
规则添加/更新时
  ↓
检测条件重叠
  ↓
检测动作矛盾
  ↓
生成冲突报告
  ↓
提供解决建议
  ↓
自动/手动解决
  ↓
更新规则状态
```
