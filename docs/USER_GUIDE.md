> 温暖陪伴，持续进化 —— 与你一起思考的智能同伴

## 🎯 这是什么？

**联盟拓荒者**不是一个冷冰冰的软件，而是一个**有温度的、不断自我生长的思考同伴**。

它会：
- 🔥 **理解你** - 识别你的意图，选择最合适的方式帮助你
- 📈 **学习你** - 从每次对话中学习，越来越懂你的偏好
- 🔄 **进化自己** - 自动优化策略，变得越来越聪明
- 💾 **记住你** - 保存有价值的经验，下次能更好地帮助你

## 🚀 快速开始

### 第一次使用

1. **启动系统**
   ```powershell
   # 双击运行
   启动.bat
   
   # 或命令行启动
   python -m uvicorn api:app --reload --port 8000
   ```

2. **打开界面**
   
   浏览器会自动打开，或手动访问: http://localhost:8000/

3. **开始对话**
   
   在输入框中输入你的问题，按Enter发送

## 🧠 它如何思考

### 意图识别

系统会自动识别你的意图类型：

| 意图 | 说明 | 示例 |
|------|------|------|
| **chat** | 日常对话 | "你好" |
| **question** | 问题咨询 | "什么是递归？" |
| **code** | 代码相关 | "写一个排序函数" |
| **calculation** | 数学计算 | "计算π的前10位" |
| **document** | 文档处理 | "总结这篇文章" |

### 模型选择

系统会根据任务选择最合适的模型：

```
代码任务 → code_light (qwen2.5-coder)
对话任务 → mindchat
复杂问题 → deepseek-chat
```

### 学习进化

每次对话后，系统会：

1. **评估质量** - 给回答打分
2. **记录经验** - 存入经验池
3. **归纳规则** - 发现模式
4. **优化策略** - 调整参数

## 🔧 配置说明

### 模型配置

编辑 `config/settings.yaml`:

```yaml
models:
  local:
    available:
      mindchat:
        enabled: true
        temperature: 0.7
      qwen2.5-coder:1.5b:
        enabled: true
        temperature: 0.5
```

### 添加远程模型

设置环境变量：

```powershell
$env:OPENAI_API_KEY = "your-key"
$env:DEEPSEEK_API_KEY = "your-key"
```

## 🐛 常见问题

### Q: Ollama连接失败？

**A**: 这是正常的！系统会自动降级到Mock适配器，不影响使用。

如需使用Ollama：
```powershell
ollama serve
ollama pull mindchat
```

### Q: 响应很慢？

**A**: 可能原因：
1. 模型正在加载（首次使用）
2. Ollama未启动，使用降级方案
3. 网络问题（远程模型）

### Q: 如何查看日志？

**A**: 后端窗口会显示详细日志，包括：
- 意图识别结果
- 模型选择决策
- 规则匹配情况
- 质量评估分数
